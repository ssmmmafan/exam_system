### 1.2 核心设计原则

| 原则 | 说明 |
|------|------|
| **RESTful 风格** | API 遵循资源导向设计，使用 HTTP 方法表示操作 |
| **无状态通信** | 每次请求独立，通过 Session/Cookie 保持登录状态 |
| **分层解耦** | 前端、后端、数据库完全独立，通过 API 交互 |
| **安全性优先** | CSRF 防护、权限校验、输入验证 |

**创建考试接口详解**：

# teachers/api_views.py - create_exam_api
def create_exam_api(request):
    # 1. 解析请求体 JSON
    data = json.loads(request.body)
    
    # 2. 数据验证
    title = data.get('title')
    duration = data.get('duration', 120)  # 默认 120 分钟
    start_time = data.get('start_time')
    end_time = data.get('end_time')
    
    # 3. 创建考试对象
    exam = Exam.objects.create(
        title=title,
        duration=duration,
        start_time=start_time,
        end_time=end_time,
        created_by=request.user,
        is_published=False
    )
    
    # 4. 处理题目数据
    questions = data.get('questions', [])
    for order, q in enumerate(questions):
        ExamQuestion.objects.create(
            exam=exam,
            question_id=q['question_id'],
            score=q['score'],
            order=order
        )
    
    return JsonResponse({'status': 'success', 'exam_id': exam.id})
```

# students/api_views.py - exam_taking_api
def exam_taking_api(request, exam_id):
    exam = Exam.objects.get(id=exam_id, is_published=True)
    now = timezone.now()
    
    # 获取或创建学生考试记录
    record, created = StudentExamRecord.objects.get_or_create(
        student=request.user,
        exam=exam,
        defaults={'answers': {}, 'start_time': timezone.now()}
    )
    
    # 处理重置后的情况：start_time 为 NULL 表示需要重新计时
    if record.start_time is None:
        record.start_time = now
        record.save()
        remaining_seconds = exam.duration * 60  # 给完整时长
    else:
        deadline = record.start_time + timedelta(minutes=exam.duration)
        remaining_seconds = max(0, (deadline - now).total_seconds())
    
    # 返回题目和剩余时间
    questions_data = []
    for question, score in get_exam_questions(exam):
        questions_data.append({
            'id': question.id,
            'type': question.type,
            'content': question.content,
            'options': get_options_dict_from_question(question),
            'score': score
        })
    
    return JsonResponse({
        'questions': questions_data,
        'time_left': remaining_seconds,
        'answers': record.answers
    })
```

#### 2.3.2 提交试卷接口详解

```python
# students/api_views.py - submit_exam_api
def submit_exam_api(request, exam_id):
    exam = Exam.objects.get(id=exam_id)
    record = StudentExamRecord.objects.get(student=request.user, exam=exam)
    
    # 防止重复提交
    if record.is_finished:
        return JsonResponse({'error': '已提交'}, status=400)
    
    # 解析答案
    data = json.loads(request.body)
    answers = data.get('answers', {})
    
    # 计算得分（客观题自动评分）
    score = 0
    for question, eq_score in get_exam_questions(exam):
        if question.type in ('essay', 'discussion'):
            continue  # 主观题跳过，留待教师批改
        
        user_answer = str(answers.get(str(question.id), '')).strip()
        correct_answer = str(question.answer).strip()
        
        if is_answer_correct(user_answer, correct_answer, question.type):
            score += eq_score
    
    # 更新记录
    record.answers = answers
    record.is_finished = True
    record.submit_time = timezone.now()
    record.score = score
    record.save()
    
    return JsonResponse({'status': 'success', 'score': score})
```

### 3.2 考试计时引擎（核心算法）

**设计原理**：以学生**进入考试的时间**为起点，而非考试发布时间。

```python
# 计时核心逻辑
def calculate_remaining_time(record, exam):
    """
    计算学生剩余考试时间
    
    参数：
        record: StudentExamRecord 对象
        exam: Exam 对象
    
    返回：
        remaining_seconds: 剩余秒数
    """
    now = timezone.now()
    
    # 情况1：首次进入或重置后进入 → 给完整时长
    if record.start_time is None:
        record.start_time = now
        record.save()
        return exam.duration * 60
    
    # 情况2：正常考试中 → 计算剩余时间
    deadline = record.start_time + timedelta(minutes=exam.duration)
    remaining = (deadline - now).total_seconds()
    
    # 情况3：时间已过 → 返回 0
    return max(0, remaining)
```

**状态转换图**：

```
                    ┌─────────────────────┐
                    │   学生进入考试       │
                    └──────────┬──────────┘
                               ▼
                    ┌─────────────────────┐
                    │  record.start_time  │
                    │     是否为 NULL？    │
                    └──────────┬──────────┘
                               │
              ┌────────────────┼────────────────┐
              │ YES           │ NO             │
              ▼               ▼                │
    ┌─────────────────┐  ┌──────────────┐     │
    │ 重置后首次进入  │  │ 正常续考     │     │
    │ start_time=now  │  │ 计算剩余时间  │     │
    │ 剩余=完整时长   │  │              │     │
    └─────────────────┘  └──────────────┘     │
                               │              │
                               ▼              │
                    ┌─────────────────────┐    │
                    │  返回剩余时间       │◄───┘
                    └─────────────────────┘
```

### 3.4 自动评分算法

```python
def is_answer_correct(user_answer: str, correct_answer: str, question_type: str) -> bool:
    """
    判断答案是否正确
    
    参数：
        user_answer: 用户答案
        correct_answer: 正确答案
        question_type: 题型（single/multiple/judge）
    
    返回：
        True 表示正确，False 表示错误
    """
    user_answer = str(user_answer).strip().upper()
    correct_answer = str(correct_answer).strip().upper()
    
    if question_type == 'single':
        # 单选题：直接比较
        return user_answer == correct_answer
    
    elif question_type == 'judge':
        # 判断题：T/F 或 对/错
        return user_answer == correct_answer
    
    elif question_type == 'multiple':
        # 多选题：按逗号分隔，不考虑顺序
        user_set = set(user_answer.split(','))
        correct_set = set(correct_answer.split(','))
        return user_set == correct_set
    
    return False
```

const api = axios.create({
    baseURL: '/api/',

api.interceptors.request.use(config => {

    }
    return config
})

api.interceptors.response.use(
    response => response,
    error => {

            window.location.href = '/login'
        }
        return Promise.reject(error)
    }
)

## 六、代码优化建议

### 6.1 当前代码问题

| 问题 | 位置 | 影响 |
|------|------|------|
| 重复代码 | `get_exam_questions` 多次调用 | 性能浪费 |
| 缺少缓存 | 考试题目每次都从数据库查询 | 响应慢 |
| 错误处理 | 部分 API 缺少 try-catch | 可能导致 500 错误 |

### 6.2 优化方案

```python
# 优化后的代码：增加缓存和错误处理
from django.core.cache import cache

def get_exam_questions_cached(exam):
    """带缓存的题目获取"""
    cache_key = f'exam_questions_{exam.id}'
    questions = cache.get(cache_key)
    
    if not questions:
        questions = list(get_exam_questions(exam))
        cache.set(cache_key, questions, timeout=3600)  # 缓存 1 小时
    
    return questions
```

## 七、总结

### 7.1 技术亮点

1. **RESTful API 设计**：规范的接口设计，易于维护和扩展
2. **个性化计时引擎**：以学生进入时间为准，支持重置和续考
3. **双层认证体系**：前端路由守卫 + 后端装饰器
4. **容器化部署**：Docker Compose 一键启动

### 7.2 技术难点

1. **考试时间管理**：处理多种边界情况（重置、续考、强制结束）
2. **并发安全**：多个学生同时提交试卷时的数据一致性
3. **主观题批改**：需要手动批改且保留批改痕迹

### 7.3 未来改进方向

1. 引入 Redis 缓存热点数据
2. 增加消息队列处理异步评分
3. 实现考试监控功能
