# 在线考试系统 - 课程大作业

## 系统概述

基于 Django + Vue 3 开发的在线考试平台，为教师和学生提供便捷的在线考试体验。

## 功能特性

### 教师功能
- 题库管理：创建、编辑、批量导入题目，支持多种题型
- 智能组卷：手动创建考试或随机组卷，支持自定义分数设置
- 防作弊措施：随机题目顺序、随机选项顺序
- 试卷批改：自动批改客观题，手动批改主观题
- 学生管理：查看考试状态和成绩统计

### 学生功能
- 用户注册和登录
- 查看所属教师发布的考试
- 在线作答，实时倒计时
- 查看历史成绩和答题详情

### 系统特点
- 响应式设计，适配不同设备
- 教师-学生关联，数据隔离
- 时区适配：中国时区（Asia/Shanghai）
- 性能优化：缓存和批量查询

## 技术栈

### 后端
- Django 6.0.3 + Python 3.12
- MySQL 数据库
- Django 缓存系统

### 前端
- Vue 3 + Vue Router 4
- Vite 5 + Axios

## 核心模块
1. 用户认证模块：注册、登录、权限管理
2. 题目管理模块：创建、编辑、导入
3. 考试管理模块：创建、组卷、管理
4. 考试执行模块：学生答题、提交
5. 成绩管理模块：计算、统计、查询

## 数据库设计

### 主要表结构
- **User**：用户信息
- **StudentProfile**：学生详细信息
- **TeacherProfile**：教师详细信息
- **Question**：题目信息
- **Exam**：考试信息
- **StudentExamRecord**：学生考试记录
- **StudentAnswer**：学生答案

## 使用指南

### 教师操作
1. 登录系统
2. 点击"题库管理"添加或导入题目
3. 点击"考试管理"创建考试或随机组卷
4. 在"待批改"标签页批改主观题
5. 查看学生成绩统计

### 学生操作
1. 注册并登录系统
2. 查看所属教师发布的考试
3. 点击"进入考试"开始作答
4. 在"历史考试"中查看成绩

## 部署说明

### 环境要求
- Python 3.12+
- MySQL 8.0+
- Django 6.0.3+

### 部署步骤
1. 安装依赖：`pip install -r requirements.txt`
2. 配置数据库（修改 `settings.py`）
3. 数据库迁移：`python manage.py makemigrations && python manage.py migrate`
4. 创建超级用户：`python manage.py createsuperuser`
5. 启动服务：`python manage.py runserver`
