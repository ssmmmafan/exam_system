批量导入题目

{% csrf_token %}
📋 必需列：
  • type - 题型（single/multiple/judge/essay/fill/discussion）
  • content - 题目内容（会自动去除"学科第X题："前缀）
  • answer - 答案
  • score - 分值（整数）
✨ 可选列：
  • options - 选项（JSON格式或分号分隔，单选题/多选题必填）
  • analysis - 解析说明
  • difficulty - 难度（1-5，默认3）
  • chapter - 章节
  • knowledge_point - 知识点
  • tags - 标签（逗号分隔）
📝 题型说明：
  • single - 单选题（需要options，答案为单个字母如A、B）
  • multiple - 多选题（需要options，答案为逗号分隔如A,B,C）
  • judge - 判断题（答案为"对"或"错"）
  • essay - 简答题（直接填写答案）
  • fill - 填空题（多个答案用分号分隔）
  • discussion - 论述题（直接填写答案）
📊 导入格式实例：
type content options answer score analysis difficulty chapter knowledge_point
single 下列哪个是正确的？ {"A":"选项A内容","B":"选项B内容","C":"选项C内容","D":"选项D内容"} A 2 本题解析... 3 第1章 知识点1
multiple 下列说法正确的有？ {"A":"选项A","B":"选项B","C":"选项C","D":"选项D"} A,B,C 4 本题解析... 4 第2章 知识点2
judge 地球是圆的。 对 1 本题解析... 1 第3章 知识点3
fill ______是重要的概念。 答案1;答案2 3 本题解析... 2 第4章 知识点4
提示：
  • CSV文件中JSON格式的options需要用双引号包裹，内部双引号用两个双引号转义
  • 题目内容中的"学科第X题："前缀会自动去除
  • 多选题答案用英文逗号分隔，如：A,B,C
  • 填空题多个答案用分号分隔，如：答案1;答案2
